# Swydo for Cursor

Use [Swydo](https://www.swydo.com) in Cursor and ask questions about your clients, reports and marketing data, right from the chat.

## Included

- `mcp.json`: the Swydo MCP server at `https://ai.swydo.com/mcp`
- `skills/swydo-reporting/`: guidance for answering reporting questions with the Swydo tools

## Setup

1. Install the plugin from the Cursor Marketplace.
2. When Cursor asks, sign in with your Swydo account. The server uses OAuth, so no API key is needed.

## Example prompts

- "Which of my clients had the biggest drop in Google Ads conversions last month?"
- "Summarize the GA4 traffic for Acme over the last 30 days."
- "Which alerts fired this week?"
