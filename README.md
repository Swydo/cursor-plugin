# Swydo Cursor plugin

Cursor Marketplace plugin for [Swydo](https://www.swydo.com). It connects Cursor to the Swydo MCP server so you can ask questions about your clients, reports and marketing data.

See [plugins/swydo](plugins/swydo/README.md) for what the plugin includes and how to use it.

## Validate

```bash
node scripts/validate-template.mjs
```
